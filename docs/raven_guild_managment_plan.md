# 레이븐2 길드 운영 페이지 핵심 기능 기획안

## 0. 문서 목적

이 문서는 레이븐2 길드 운영을 위한 웹 페이지 또는 관리자 페이지를 만들 때 필요한 핵심 기능을 정리한 기획 초안이다.

단순 커뮤니티 페이지가 아니라, 길드장이 실제로 운영에 사용하는 것을 기준으로 다음 항목을 중심에 둔다.

- 길드원 관리
- 콘텐츠 일정 관리
- 길드 던전 운영
- 어비스 운영
- 필드 보스 / 균열 / 고대 성채 참여 관리
- 보상 분배 관리
- 공지 및 규칙 관리
- 참여율 / 기여도 통계

---

## 1. 참고한 게임 시스템

공식 가이드의 메인 시스템에는 다음과 같은 길드 운영 관련 콘텐츠가 포함되어 있다.

- Guild Dungeon
- Guild
- Rankings
- PvP
- Field Bosses
- Rift
- Abyss
- Ancient Fortress
- Mission Itinerary
- Guild Union
- Dimensional Rift
- Clash

따라서 길드 운영 페이지는 단순히 길드원 명단만 관리하는 구조보다, **일정 + 참여 + 전리품 + 분배 + 역할 배정**을 함께 관리하는 구조가 적합하다.

---

## 2. 전체 메뉴 구조 추천

```text
길드 홈
 ├─ 대시보드
 ├─ 길드원 관리
 ├─ 콘텐츠 일정표
 │   ├─ 길드 던전
 │   ├─ 어비스
 │   ├─ 필드 보스
 │   ├─ 균열
 │   ├─ 고대 성채
 │   └─ 기타 이벤트
 ├─ 참여 체크
 ├─ 보상 분배
 ├─ 파티 편성
 ├─ 공지사항
 ├─ 가입 신청
 └─ 운영 설정
```

핵심은 **대시보드 → 일정 확인 → 참여 체크 → 결과 기록 → 보상 분배** 흐름이다.

## 3. 대시보드

길드장이 접속하자마자 오늘 해야 할 일을 볼 수 있어야 한다.

### 주요 표시 항목

| 항목 | 설명 |
|---|---|
| 오늘의 콘텐츠 | 오늘 예정된 길드 던전, 어비스, 필드 보스, 균열, 고대 성채 |
| 이번 주 길드 던전 상태 | 미진행 / 예정 / 완료 |
| 어비스 운영 상태 | 오늘 진행 예정 여부, 입장 가능 인원, 보스 목표 |
| 참여 신청 현황 | 참석 / 불참 / 미응답 인원 |
| 최근 미접속자 | 최근 접속일 기준 장기 미접속 길드원 |
| 분배 대기 전리품 | 아직 지급되지 않은 길드 전리품 |
| 긴급 공지 | 오늘 집결 시간, 디스코드/오픈채팅 안내 |

### 대시보드 카드 예시

```text
[오늘의 일정]
21:00 균열
21:30 어비스 집결
22:00 길드 던전

[어비스]
목표: 3번 사냥터 + 보스 확인
참석: 24명 / 미응답: 8명
입장권 확인 필요: 5명

[분배 대기]
영웅 장비 1개
도안 조각 상자 3개
인장 상자 2개
```

## 7. 어비스 운영

어비스는 레이븐2의 최상위급 사냥/보스 콘텐츠 성격이 강하므로, 길드 운영 페이지에서 별도 메뉴로 분리하는 것이 좋다.

업데이트 소개 자료 기준으로 어비스는 레벨 55 이상 이용자가 `심연의 초대장`을 통해 입장할 수 있는 상위 사냥 콘텐츠로 소개되었고, 최상위 필드 보스 `쾌락의 피조물`과 높은 경험치, 영웅 등급 장비 획득 가능성이 언급되었다.

따라서 어비스 운영은 일반 필드 사냥보다 다음 요소를 더 중요하게 봐야 한다.

- 입장 가능 조건
- 입장권 보유 여부
- 사냥터 배정
- 보스 등장 / 제보 / 대응
- 적대 길드 또는 경쟁 길드 대응
- 획득 아이템 기록
- 참여자 기준 분배

### 7-1. 어비스 메뉴를 따로 두는 이유

| 이유 | 설명 |
|---|---|
| 상위 콘텐츠 | 일반 길드원 전체보다 준비된 인원 중심 운영이 필요 |
| 입장 조건 존재 | 레벨, 입장권, 스펙 체크가 필요 |
| 사냥터 분산 가능성 | 여러 사냥터 또는 층/구역별 배치 관리 필요 |
| 보스 대응 | 보스 발견 시 빠른 집결과 역할 배정 필요 |
| 보상 민감도 높음 | 영웅 장비 등 고가치 보상 기록 필요 |
| PvP 변수 | 최상위 사냥터 특성상 경쟁 길드 대응 기록 필요 |

### 7-4. 어비스 사냥터 배정

어비스가 여러 사냥터 또는 구역으로 나뉘는 구조라면, 길드원들을 한곳에 몰아넣기보다 역할별로 나누는 기능이 유용하다.

### 배정 예시

```text
[어비스 배정표]

1구역 사냥조
- 목적: 안정 파밍
- 인원: 10명
- 기준: 중간 전력 이상

2구역 사냥조
- 목적: 고효율 파밍
- 인원: 10명
- 기준: 상위 전력

보스 대기조
- 목적: 쾌락의 피조물 발견 시 즉시 집결
- 인원: 8명
- 기준: 상위 전력 + 디스코드 가능

정찰조
- 목적: 보스/적대 길드 위치 제보
- 인원: 3명
```

### 사냥터 배정 기능

| 기능 | 설명 |
|---|---|
| 드래그 앤 드롭 배정 | 길드원을 사냥터 카드에 끌어다 배치 |
| 자동 추천 배정 | 공격력/방어력/명중 기준 추천 |
| 클래스 균형 표시 | 특정 파티에 딜러만 몰리는 문제 방지 |
| 디스코드 가능 인원 표시 | 지휘가 필요한 조에 우선 배치 |
| 예비 인원 지정 | 사망, 이탈, 미접속 시 대체 |

| 결과 기록 | 처치 성공/실패, 획득 아이템 |
| 경쟁 길드 기록 | 교전 여부, 방해 길드 |

### 균열

균열은 대규모 인원이 함께 참여하는 콘텐츠로 소개되었으므로, 길드 단위로는 참여율 관리에 적합하다.

| 기능 | 설명 |
|---|---|
| 반복 일정 등록 | 매일 또는 특정 요일 |
| 참여 신청 | 참석 / 불참 |
| 기여도 메모 | 주요 참여자 기록 |
| 보상 기록 | 주요 보상 획득 여부 |
| 미참여자 확인 | 길드 활동 관리용 |

### 고대 성채

고대 성채는 월드 단위 PvPvE 콘텐츠로 소개되며, 상위 길드 중심의 경쟁 콘텐츠 성격이 강하다.

| 기능 | 설명 |
|---|---|
| 참가 자격 관리 | 참여 가능한 길드원 / 핵심 인원 |
| 입장 인원 관리 | 제한 인원 기준 편성 |
| 지휘 체계 | 총지휘, 파티장, 정찰, 후방 지원 |
| 파티 편성 | PvP/PvE 역할별 파티 구성 |
| 전투 기록 | 교전 길드, 보스 대응, 결과 |
| 보상 분배 | 참여 기준 보상 지급 |

## 10. 보상 분배 관리

길드 운영에서 가장 민감한 부분이다. 반드시 투명하게 기록해야 한다.

### 분배 방식 추천

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| 포인트제 | 참여 포인트로 우선권 부여 | 공정성 높음 | 관리 필요 |
| 경매제 | 길드원 입찰 | 단순함 | 자본 많은 유저 유리 |
| 운영진 지정 | 필요한 인원에게 지급 | 전력 강화에 유리 | 불만 가능성 |
| 랜덤 추첨 | 참여자 중 추첨 | 간단함 | 기여도 반영 약함 |

가장 추천하는 방식은 **포인트제 + 운영진 승인**이다.

### 포인트 예시

| 활동 | 포인트 |
|---|---:|
| 길드 던전 참여 | +10 |
| 어비스 참여 | +10 |
| 어비스 보스 참여 | +15 |
| 필드 보스 참여 | +5 |
| 균열 참여 | +5 |
| 고대 성채 참여 | +20 |
| 정찰 / 제보 기여 | +3 |
| 무단 불참 | -5 |
| 허위 참여 체크 | -10 |

## 17. 핵심 요약

레이븐2 길드 운영 페이지에서 가장 중요한 기능은 다음 6개다.

1. **길드원 관리**
    - 레벨, 클래스, 공격력, 방어력, 명중, 최근 접속일 관리

2. **콘텐츠 일정 관리**
    - 길드 던전, 어비스, 필드 보스, 균열, 고대 성채 일정 등록

3. **참여 체크**
    - 참석 예정과 실제 참석을 분리해서 기록

4. **어비스 운영**
    - 입장권, 사냥터 배정, 보스 제보, 파티 편성, 전리품 기록

5. **보상 분배**
    - 포인트제 또는 운영진 승인 방식으로 투명하게 기록

6. **공지 / 규칙**
    - 집결 시간, 분배 기준, 어비스 준비물, 불참 규칙 안내

초기 개발에서는 **일정표 + 참여 체크 + 어비스 운영 + 보상 분배**를 우선 구현하는 것이 가장 효율적이다.
