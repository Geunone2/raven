# 이용약관 / 개인정보 처리방침 (`/terms`, `/privacy`)

## 목적/기능

두 페이지 모두 서버 데이터/서버 액션 없이 하드코딩된 텍스트를 `whitespace-pre-line`으로 그대로 렌더링하는 완전 정적 페이지입니다. 로그인 여부와 무관하게 접근 가능합니다.

## 파일 구성

```
app/(user)/terms/page.tsx     — TERMS_CONTENT 상수 (파일 내부에 하드코딩)
app/(user)/privacy/page.tsx   — PRIVACY_CONTENT 상수 (파일 내부에 하드코딩)
```

외부 컴포넌트/액션 의존성 없음. 회원가입/로그인 등 다른 페이지에서 이 두 경로로의 링크가 있는지는 각 페이지에서 별도 확인이 필요합니다(이 문서 작성 시점 기준으로는 `login`/`signup` 페이지에 직접 링크가 없습니다).
